📊 API ENDPOINTS
================================================================================

Authentication:
POST   /api/auth/register           → Create account
POST   /api/auth/login              → Login
GET    /api/auth/me                 → Verify token

Bookings:
GET    /api/bookings/date/:date                    → Day's bookings
GET    /api/bookings/calendar/:month/:year        → Month overview
POST   /api/bookings                              → Create booking
GET    /api/bookings/my-bookings                  → User's bookings
GET    /api/bookings/admin/all                    → All bookings (admin)
GET    /api/bookings/admin/stats                  → Stats (admin)
DELETE /api/bookings/:id                          → Cancel booking

🐛 TROUBLESHOOTING
================================================================================

npm: command not found
→ Install Node.js from https://nodejs.org

Port 5000 already in use
→ set PORT=3001 && npm start

npm install fails
→ Try: npm install --legacy-peer-deps

Database won't start
→ Delete data/zetu.db and restart

Detailed troubleshooting in QUICKSTART.md
